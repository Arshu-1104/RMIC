## Notes

- `allowed_args` catches attacks here only because `prompts/v2` plans use a fixed, hand-written argument schema. On 97 historical legitimate LLM plans with free-form JSON, an allowlist blocked 22–69 (23–71%), which is why `financial_agent_hardened` ships patterns only.
- The account patterns in `financial_agent_hardened` blocked 0/97 historical legitimate LLM plans.
- Deny packs and prohibited terms are wording heuristics; see the README warning.
