# examples/

Runnable SDK examples; `quickstart.py` runs offline with no API key.

| File | Shows |
|---|---|
| `quickstart.py` | `Guard` with the bundled sealed `financial_agent` contract: PASS and BLOCK. |
| `basic_enforcement.py` | Parameter bounds and data-scope rules. |
| `contract_creation.py` | Writing a contract in code (beginner and advanced API). |
| `identity_drift.py` | Semantic IDS scoring (experimental). |
